LaSb R(B)/R(0) simulator

비편광·수직입사·벌크, Faraday 기하 (B ∥ z ∥ k). 규약: e−iωt, Gaussian. ε±(ω)=ε∞ − Σ ωp²∕[ω(ω∓ωc+iγ)], ωc = q B∕m*c (전자 ωc<0). 탐색용 — 정량 피팅은 Python.

Model

γ(B) = γ[1 + b·(B/17.5)p], b는 17.5 T에서의 상대 변화량. 문헌에서 실제로 보고된 지수:
p = +1 — 양자극한의 3D→1D 교차, 1/τ ∝ ν_B(DOS) ∝ B. Li et al., PRB 74, 195404 (2006), HOPG 자기반사율 18 T.
p = +2/3 — 통상 3D 전자기체의 불순물 산란 (Maniv & Vagner, PRB 38, 6301). Cheng et al., PRL 122, 097401 (2019)의 전자.
p = −1 — 하전 불순물 산란 하 Dirac LL 폭 (Yang, Peeters & Xu, PRB 82, 075401). 같은 논문의 정공, 그리고 Shao et al., Nano Lett. 17, 980 (2017)의 표면상태.
B²은 대칭성 전개일 뿐 보고된 예가 없습니다. 또 위 기제들은 모두 양자극한(최저 LL만 점유)에서의 결과입니다 — LaSb는 13 T에서 l_B·k_F ≈ 17로 다수 LL이 점유된 반고전 영역이라 그대로 적용하기 어렵습니다.
ε∞(B) = ε∞ + a·B², γ(B) = γ(1+b·B²). B의 짝수차만 허용(시간반전). ωc와 달리 두 편광에 동일 작용 → edge 분열이 아니라 이동·뭉갬으로 나타남.
Σωp_j²/(60γ_j) = 목표를 강제. 「반대쪽 보상」은 편집한 γ를 유지하고 나머지 γ를 풀어 맞춤(해가 없으면 비례로 대체), 「비례 스케일」은 두 γ를 같은 배수로 조정. ωp·목표 변경 시엔 항상 비례.

출력

저장 열: ω, R_merged(정합만), R_Au, R_absolute.

1. 규약과 단위

시간 의존성 e−iωt, Gaussian(cgs), 주파수는 파수 ω [cm⁻¹].
기하: Faraday, B ∥ ẑ ∥ k, 시료 표면 ⊥ ẑ. 수직입사·반무한 벌크.
σ의 단위는 (Ω·cm)⁻¹, ρ는 μΩ·cm.

2. 단일 캐리어의 운동방정식 → 전도도 텐서

m*(dv/dt) = q(E + v×B/c) − m*γv,   v ∝ e−iωt 대입:
  (−iω + γ)v = (q/m*)E + (q/m*c)(v×Bẑ)

x,y 성분을 풀면 (ωc ≡ qB/m*c, 부호 포함; 전자 ωc<0):
  σxx = (ωp²/4π)·(γ − iω) / [(γ − iω)² + ωc²]
  σxy = (ωp²/4π)·ωc / [(γ − iω)² + ωc²]
  σyy = σxx,   σyx = −σxy,   σzz는 B와 무관.

ω→0에서 σxx → σ₀/(1+(ωc/γ)²), σxy → σ₀(ωc/γ)/(1+(ωc/γ)²), σ₀ = ωp²/4πγ. ωc/γ = μB이므로 표준 반고전 식과 동일.

3. 다중 Drude: 텐서 단순 합

각 캐리어는 독립적으로 전류를 나르므로 전도도가 더해집니다(저항이 아니라):
  σxxtot = Σj σxx,j,   σxytot = Σj σxy,j
각 j는 자기 자신의 (ωp,j, γj, ωc,j)를 가지며 ωc,j의 부호가 캐리어 종류를 담습니다. Lorentz 오실레이터도 같은 방식으로 ε에 더해집니다.

주의: ρ는 더하면 안 됩니다. 텐서를 합한 뒤에 역행렬을 취합니다.

4. 원편광 기저 — 왜 대각화가 되는가

E± = Ex ± iEy 로 두면 회전대칭성(z축 둘레)에 의해 2×2 반대칭 텐서가 대각화됩니다:
  σ± = σxx ∓ i σxy  →  ε± = εxx ∓ i εxy

단일 캐리어에 대입하면 분모가 인수분해되어
  ε±(ω) = ε∞ − Σj ωp,j² / [ω(ω ∓ ωc,j + iγj)]
이 형태를 코드가 직접 사용합니다. 다중 캐리어에서도 각 j의 ±조합이 그대로 더해지므로 텐서 합과 완전히 동치입니다 — 아래 검증표 참조.

5. 반사율

각 원편광 모드는 독립적으로 전파: N± = √ε± (분지: Im N ≥ 0), r± = (1−N±)/(1+N±).
비편광 입사 → R = ½(|r+|² + |r−|²).

중요: 이 평균에서 σxy의 1차항이 정확히 소거됩니다. 따라서 비편광 반사율로는 σxy를 얻을 수 없고, 접근 가능한 것은 |ωc,j|와 ωp,j 조합뿐입니다. edge 분열 δ = ½|Σj fjωc,j| (fj = ωp,j²/Σωp²)이 ratio에 2차로 나타납니다: R(B)/R(0) − 1 ≈ (δ²/2)·R₀″/R₀.

6. DC 자기수송 — 같은 텐서의 ω→0 극한

σxx = Σj σj/(1+βj²),   σxy = Σj σjβj/(1+βj²),   βj = sjμjB (s = −1 전자, +1 정공)

2×2 역행렬:
  ρxx = σxx/(σxx²+σxy²),   ρxy = σxy/(σxx²+σxy²)

Onsager: ρxx는 B의 우함수, ρxy는 기함수 — 코드에서 수치적으로 정확히 성립.

7. 파라미터 변환

τ = 1/(2πcγ) → τ[fs] = 5308.84/γ  ·  μ = eτ/m* → μ[cm²/Vs] = 9336/(γ·m*/me)
n = 1.11486×10¹³·(m*/me)·ωp² [cm⁻³]  (= πc²me/e² 계수)
ωc = ±0.93373·B[T]/(m*/me) [cm⁻¹]  ·  ωc/γ = μB  ·  n e μ = ωp²/(60γ) = σDC

8. 자기장 의존 ε∞, γ

시간반전 대칭에 의해 스칼라량은 B의 짝수차만 허용:
  ε∞(B) = ε∞ + a·B²,   γj(B) = γj(1 + bj·B²)
이들은 두 원편광에 동일하게 작용하므로 edge를 분열시키지 않고 이동·뭉갬만 만듭니다 (ωc와 구별되는 서명).
γ(B)는 DC 수송에도 반영됩니다: μj(B) = 9336/(γj(B)·mj*).
해석 주의: 고전 Drude에서 자기저항은 이미 ωc가 담당하므로, bγ는 그 너머의 효과(Landau 준위, 비균질성)로만 해석해야 이중계산이 아닙니다.
